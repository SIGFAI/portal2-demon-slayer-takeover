# Demon Slayer Takeover

**Portal 2** × Demon Slayer · visual · idea by the team

Bring Demon Slayer into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Portal 2 into Demon Slayer: haori-checkered cubes, demon turrets, and a giant Muzan that burns when the Breathing slashes land.

## Install

Copy the mod folder's contents into your Portal 2 game folder as a custom game folder (for example a folder named sigf) and launch Portal 2 with -game sigf and sv_cheats 1. Load any test chamber and watch the haori cubes fall and the demons arrive.
